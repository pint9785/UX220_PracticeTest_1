The comparisons and contrasts between old fashioned typesetting with desktop publishing, html and css.

Even though old fashioned typesetting with desktop publishing, html and css have some similarities, they have many differences. Firstly, old fashioned typesetting is physical, it's on a paper with set typography blocks with a set layout. With HTML, it's more digital with it being on a computer, laptop, or iphone screen. HTML's whole job is to focus on headers, body text, footers, etc. It takes care of the content, not about how it looks. Just like HTML, CSS is digital, but it focuses mostly on the look of the content, such as the styles; the colours, the fonts, the look.
