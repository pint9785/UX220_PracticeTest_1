Three Diferences Between Google Docs and HTML Documents

The three key differences I have noticed when writing in a Google Docs instead of an html document would be that, firstly, through google docs, things like suggestions, spelling mistakes, definitions, etc can pop up when writing, were as an html document does not show things like spelling mistakes with a red line under the mistake. Secondly, another key difference I've noticed is that when in Google Docs, changes like text colours, fonts, sizes can be seen right away whereas in html you have to code those changes and then see the page to see if it worked. Using Google Docs, you can see changes you're making on the spot.
